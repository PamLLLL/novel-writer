## AI高频词替代方案表

写作时，如果脑中浮现左边的表达，立刻用右边的方式替代：

| 想写的AI表达 | 替代方案 |
|---|---|
| 不禁 + 动作 | 直接写动作，删掉"不禁"。"不禁攥紧了拳"→"攥紧了拳" |
| 缓缓 | 90%的情况直接删掉。需要慢动作时换具体描写："他一步一步挪过去" |
| 淡淡地说 | 删掉"淡淡地"，用动作代替语气标签："他没抬头，'知道了。'" |
| 微微一笑 / 嘴角微微上扬 | 全文最多1次。替代："她咧嘴笑了"/"她没忍住，笑出了声"/"她哼了一声" |
| 目光深邃 / 眼神深邃 | 写具体行为："他盯着窗外的暮色，半天没说话" |
| 心中涌起一股XX | 用身体反应替代："鼻子一酸"/"胃里发紧"/"手心冒汗"/"后背一凉" |
| 不由自主 | 删掉，直接写动作 |
| 仿佛 / 宛如 / 好像 | 大部分时候直接删掉，写断言。"仿佛一把刀"→"那是一把刀" |
| 似乎 | 如果角色真的不确定，用具体表现："她皱了皱眉"代替"她似乎不太高兴" |
| 竟然 / 居然 | 用角色反应展示惊讶："他愣了一下"/"杯子从手里滑下去"/"她停下了筷子" |
| 一丝XX | 换成具体可观测的表现。"一丝笑意"→"嘴角动了动" |
| 渐渐 | 删掉或用时间锚点替代："天黑了"比"天色渐渐暗了下来"干脆 |
| 映入眼帘 | 直接写看到的东西。"一座老宅映入眼帘"→"门口停着辆落灰的三轮车，门匾上的字看不清了" |
| XX般的 | 减少比喻堆砌。一段话最多一个比喻 |
| 脸上露出XX的表情 | 写具体的面部变化："他咬了咬嘴唇"/"她的眼皮跳了一下" |

## 句式规避

| AI典型句式 | 人味写法 |
|---|---|
| 连续3个以上排比句 | 拆掉，只留最有力的那一句 |
| "不仅...更..." 递进 | 换成两个独立短句 |
| "然而" 开头转折 | 直接写转折后的事。或用"但是"——更口语 |
| "与此同时" 切场景 | 空一行，直接写新场景。不用旁白过渡 |
| "值得一提的是" | 删掉，直接写 |
| 每段结尾做情感总结 | 删掉总结句，用动作或对话收尾 |

## 对话去AI味

- 真人说话用短句，一次说1-2句话，不会一口气说一大段
- 真人会省略主语："知道了"而不是"我知道了"
- 真人有语气词和口癖：嗯、啊、得了、行吧、切
- 真人会打断别人、会跑题、会答非所问
- 潜台词比直白表达有力："随你"比"我不同意但我不想吵"好
