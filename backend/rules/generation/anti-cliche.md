## 情节反套路

- 人物要有缺点和成长弧线，拒绝"龙傲天"式完美主角
- 拒绝无意义的打脸桥段堆砌——每次冲突必须推动情节或改变角色关系
- 角色想要变强，用行动展现，删掉空洞宣言（"我要保护身边的人"）
- 场景描写服务于情绪和情节，一句环境描写足矣，多了就是注水
- 每个角色说话方式必须不同——用词、句长、语气词有区分
- 成长要有过程和代价，拒绝"闭关出关就无敌"
- 伏笔自然埋设，巧合每章最多1个，误会必须在3000字内解开
- 配角有自己的立场和动机，反派有合理的利益驱动

## 展示而非讲述（Show don't tell）

遇到左边的冲动时，用右边的方式写：

| 想写的（讲述） | 应该写的（展示） |
|---|---|
| 她很紧张 | 她攥紧了袖口 / 她咽了口唾沫 |
| 他非常生气 | 他把杯子往桌上一墩，水溅出来 |
| 她感到一阵悲伤 | 她把勺子放回碗里，汤凉了，一口没喝 |
| 他看起来很狼狈 | 他的衣领歪了，鞋上全是泥 |
| 她是一个善良的人 | 她把自己的伞塞给老太太，自己淋着雨跑了 |
| 他们关系很好 | 他顺手把她碗里的香菜挑走了，两人都没说话 |
| 气氛很尴尬 | 没人说话，只听到空调嗡嗡响 |
| 他下定了决心 | 他把烟掐了，站起来 |

## 人名使用

- 同一段落中角色名字最多出现2次，之后用代词（他/她）、称谓或描述替代
- 连续两句话不能以同一个名字开头
- 善用"对方"、"来人"、"那人"等替代
- 对话中少叫对方名字——真人聊天很少每句都喊名字

## 情节反重复

- 每章核心冲突/事件类型必须与前面章节不同
- 角色的情感反应要有变化——不能每次难过都"红了眼眶"，每次愤怒都"攥紧拳头"
- 不同场景的描写用不同意象，全文只允许"月光如水"出现1次
- 对话模式要有变化——不能每次冲突都是"质问→解释→和好"
