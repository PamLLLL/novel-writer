# 知乎盐选平台规则

## 一、基本要求

- 篇幅 1-3 万字，短小精悍
- 主线贯穿，支线明晰，反转悬念紧凑
- 节奏明快不拖沓，跌宕起伏
- 人物饱满有成长，引发共鸣和思考
- 通俗流畅口语化，简洁明了，排版清晰

## 二、选题三要素

1. **题材**：你感兴趣 / 擅长有积累有作品 / 平台读者反响热烈
2. **主题**：源于生活、高于生活，不以三俗博眼球，不以立场引矛盾
3. **卖点**：选题新颖、设定出彩、人物有梗、反转不断、每段埋钩子

## 三、盐选结构（核心！严格执行）

| 位置 | 要求 |
|------|------|
| 前 200 字 | 拎主线、找看点，抛出最吸引人的悬念 |
| 前 1000 字 | 明确主角欲望 + 动机 |
| 前 3000 字 | 预埋核心悬念 |
| 前 1/3 或 1/2 | 设置大转折或小高潮 |

### 发展阶段
- 接住开头抛出的主线 + 欲望 + 动机
- 情节发展要快，冲突要激烈
- **每千字至少一个看点**

### 高潮部分
- 上承发展、下启结局
- 全文最大的转折点
- 悬念在此解开：满足读者期待感，意料之外、情理之中

### 收尾阶段
- 人物结局交代清楚
- 升华主题，耐人寻味
- 价值观飙升

## 四、人物要求

- 人物关系简单，开篇人物**不超过 3 个**
- 人设真实细腻、立体丰满、个性突出
- 极致性 / 反差萌 / 两极反转
- 干净利索有张力

## 五、编辑选稿标准

1. 一句话能提炼出核心亮点
2. 开篇干脆不拖沓，把最吸引人的情节、主角最核心的欲望提炼出来
3. 中段三看点：核心悬念、人物张力、文稿创意——用新视角解决故事中的旧元素
4. 结局形成完整闭环，危机解除后让读者长吁一口气

## 六、盐选 vs 故事回答开头差异

- **盐选专栏**（书店式场景）：读者专门来读，有耐心 → 可以从事件背景切入
- **故事回答**（社区式场景）：读者只是对问题感兴趣 → 必须从事件高潮切入

# 知乎类型专属规则

> 以下规则仅在对应类型时由 AI 参考使用。

## 【古言】知乎古言写作规则

### 定义
古代或架空古风社会文化背景下，以男女主角感情线为主线的故事。鼓励将传统元素和创新元素融合。

### 常见题材
重生、穿书、宫斗宅斗、权谋、仙侠、种田经商

### 苏点设计
- 男女主情感暧昧的极限拉扯感
- CP 感是核心：妖娆笨蛋美人 vs 运筹帷幄皇子，病娇恋爱脑王爷 vs 暴躁小娇妻
- 男主人设尽可能符合女性幻想（可以腹黑病娇，但要有讨喜的点）
- 女主要有亮点（性格优势或金手指）

### 虐点设计
- 男女主身份地位对立
- 遗憾错过、宿命感冲突
- 虐要有度，有回甘

### 古言世界观构建
- 完整的时代社会体系，让故事更有说服力
- 宅斗文：重点放在皇权制度、官职、后妃等级
- 玄幻文：修炼等级体系、神魔鬼怪妖兽设定

### 代入感提升 5 法
1. **开篇强冲突**：情绪是进入故事最快的方式
2. **主角人设真实可感**：高地位人设（公主/皇后）用情绪加强代入
3. **多用细节描写**：用细节代入角色感受
4. **动机合理化**：主角动机需结合所处环境和周围人态度
5. **配角特色化**：必要配角要有辨识特征（脸上有疤、说话结巴等），打破陌生感

### 古言子类型
- **追妻文**：女性掌握主动权 + 打脸渣男，双倍爽
- **甜宠文**：人物关系张力 + 情感拉扯，可叠加「先婚后爱」
- **权谋文**：商贾世家或后宅，多和大女主元素结合，融合个人命运与家国情怀
- **脑洞文**：情节富有创意（动物主角、快穿、金手指等）
- **玄幻文**：玄幻背景下的爱情，通过修炼或打怪推动情节
- **同人文**：二次创作，注意版权选公版内容
